# Обновления

«Кладезъ» сам узнаёт, вышла ли новая версия. Для этого он обращается только к открытому каталогу проекта и ничего не сообщает о вас.

## Как обновить программу

Когда выйдет новая версия, на главной странице появится надпись **«Вышло обновление Кладезя!»**.

1. Откройте Настройки → **[Проверить обновления](/settings/update)**.
2. Нажмите **«Начать обновление»**.
3. Подождите несколько минут. Во время обновления страница может ненадолго показать ошибку связи — так и должно быть. Когда всё закончится, страница обновится сама.

Скачанная библиотека, карты и ваши настройки при обновлении сохраняются.

Иногда вместе с новой версией выходит файл **«Кладезъ-обновление-…»** для Windows. Скачайте его там же, где брали установщик, и запустите, как при установке. Библиотеку он не трогает.

## Автообновление

В Настройках → **[Проверить обновления](/settings/update)** можно включить:

- **Автообновление программы** — новые версии «Кладезя» ставятся сами;
- **Автообновление приложений** — то же для программ со Склада;
- **Автообновление материалов** — новые выпуски Википедии и других материалов скачиваются сами. Учтите: это большие файлы.

Обновления ставятся в выбранное время, например ночью. Если интернета нет — ничего не происходит, программа попробует позже.

## Обновлять ли материалы

Не обязательно. Википедия меняется медленно, а для жизни без интернета прошлогодний выпуск почти так же полезен. Обновляйте, когда есть хороший интернет и свободное место.
