# Обновления

«Кладезъ» сам узнаёт, вышла ли новая версия. Для этого он обращается только к открытой странице проекта на GitHub и ничего не сообщает о вас.

## Как обновить программу

Когда выйдет новая версия, на главной странице появится надпись **«Вышло обновление Кладезя!»**.

1. Откройте Настройки → **[Проверить обновления](/settings/update)**.
2. Нажмите **«Скачать новую версию»** — откроется страница выпуска на GitHub.
3. Скачайте файл **«Kladez-Setup-….exe»** и запустите его, как при первой установке.
4. Установщик сам увидит прежнюю версию и обновит её. Через несколько минут Кладезъ запустится сам.

Скачанная библиотека, карты и ваши настройки при обновлении сохраняются. Прежняя версия удаляется сама — место на диске не прибавляется.

Что изменилось — в разделе [Что нового](/docs/release-notes).

## Автообновление материалов

В Настройках → **[Проверить обновления](/settings/update)** можно включить:

- **Автообновление приложений** — новые версии программ со Склада ставятся сами;
- **Автообновление материалов** — новые выпуски Википедии и других материалов скачиваются сами. Учтите: это большие файлы.

Обновления ставятся в выбранное время, например ночью. Если интернета нет — ничего не происходит, программа попробует позже.

## Обновлять ли материалы

Не обязательно. Википедия меняется медленно, а для жизни без интернета прошлогодний выпуск почти так же полезен. Обновляйте, когда есть хороший интернет и свободное место.
