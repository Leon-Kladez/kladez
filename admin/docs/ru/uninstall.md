# Удаление

«Кладезъ» удаляется как любая другая программа Windows.

1. Откройте **«Пуск» → «Параметры» → «Приложения»**.
2. Найдите в списке **«Кладезъ»** и нажмите **«Удалить»**.
3. Программа спросит: **«Удалить также скачанную библиотеку (статьи, карты, книги)?»**
   - **«Нет»** — библиотека останется на диске. Если потом поставить «Кладезъ» снова, ничего не придётся скачивать заново.
   - **«Да»** — библиотека удалится, место на диске освободится.
4. Дождитесь конца удаления.

Ярлык на рабочем столе, автозапуск и папка с журналами удаляются вместе с программой. Компоненты Windows, которые включил установщик (подсистема Windows для Linux), остаются — они не мешают и могут пригодиться другим программам.

## Если нужно только освободить место

Удалять программу не обязательно. Ненужные материалы можно удалить по одному: Настройки → **[Мои материалы](/settings/zim)**, а карты — в Настройках → **[Управление картами](/settings/maps)**.
