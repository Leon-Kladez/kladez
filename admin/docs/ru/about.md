# О программе

**«Кладезъ» — кладезь знаний.** Бесплатная программа на русском языке: библиотека полезных знаний, которая хранится у вас дома и работает без интернета.

## Зачем

Интернет может пропасть: авария, отключение, глушь. А знания всё больше живут только на чужих серверах. «Кладезъ» нужен, чтобы самое полезное — медицина, Википедия, учебники, карты — хранилось у людей дома и было под рукой всегда.

## Наши правила

- **Бесплатно.** Без рекламы и платных «порций» знаний.
- **Без слежки.** Программа ничего не сообщает о вас ни в какие службы. Она обращается в интернет только чтобы скачать выбранные вами материалы и узнать, есть ли обновления.
- **Открыто.** Код программы и список материалов открыты: любой может проверить, что внутри.
- **Только то, что можно раздавать.** Мы берём материалы, которые разрешено распространять, и для каждого источника записываем его лицензию.
- **Нейтрально.** Только полезные знания, без политики.

## Откуда материалы

«Кладезъ» сам не хранит гигабайты статей: он скачивает их напрямую из открытых источников — в основном из каталога [Kiwix](https://kiwix.org), который выпускает Википедию и другие материалы для чтения без интернета. Карты собраны из [OpenStreetMap](https://www.openstreetmap.org) (© участники OpenStreetMap).

Текст лицензии и сведения об авторах — в папке программы (файлы `LICENSE.txt` и `NOTICE.txt`) и в меню «Пуск» → «Кладезъ» → «Сведения о программе».
