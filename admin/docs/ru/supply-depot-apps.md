# Программы со склада

На **[Складе программ](/supply-depot)** можно поставить в «Кладезъ» дополнительные программы. Каждая работает на этом компьютере, без интернета. Когда программа установится, на её карточке появится кнопка **«Открыть»**.

Здесь коротко написано, как начать работу с каждой программой: нужен ли вход, какой пароль на первый раз и где лежат файлы. Как пользоваться самой программой — на её сайте (ссылки ниже; сайты в основном на английском).

## Управление программами

Склад программ виден на главной странице в **продвинутом режиме**. У каждой установленной программы на карточке есть кнопка **«Открыть»** и меню **«Управление»**. На виду в меню только простое:

- **Справка** — открывает раздел этой страницы про программу.
- **Перезапустить, если не работает** — программа ненадолго остановится и запустится снова. Помогает чаще всего.
- **Обновить** (если вышла новая версия). Если после обновления программа не запустилась, «Кладезъ» сам вернёт прежнюю версию.
- **Удалить** — программа удаляется с компьютера, а ваши книги, карты и файлы остаются на диске.

Остальное спрятано под пунктом **«Для опытных»**: запуск и остановка, **Журнал** и **Нагрузка** (что программа пишет о своей работе и сколько памяти занимает), **Изменить** (порты, папки, переменные, ограничения памяти), **Свой адрес**, автообновление и **Переустановить начисто** (стирает данные программы).

## Своя программа

Опытные пользователи могут добавить свою программу (контейнер Docker) кнопкой на Складе программ. «Кладезъ» её запустит, но справки и поддержки для неё нет — смотрите документацию самой программы.

## Stirling PDF {% #stirling-pdf %}

Всё для PDF-файлов: объединить, разделить, сжать, повернуть, распознать текст на скане, поставить или снять пароль.

**Вход:** не нужен, программа открывается сразу.

**Файлы:** вы выбираете PDF на своём устройстве («Открыть с компьютера»), а результат скачиваете обратно. На компьютере с «Кладезем» файлы не хранятся.

Сайт: [stirlingpdf.com](https://stirlingpdf.com)

## Файлы {% #file-browser %}

Просмотр файлов «Кладезя» в браузере: загрузить, скачать, переименовать, удалить.

**Вход:** имя `admin`, пароль `kladez`. **Сразу смените пароль** (Настройки → Профиль): он одинаковый у всех, кто поставил программу, и любой в вашей сети мог бы войти.

**Осторожно:** здесь удаляются настоящие файлы. Служебные папки (модели ИИ, база поиска) скрыты, чтобы их нельзя было стереть случайно.

Сайт: [filebrowser.org](https://filebrowser.org)

## Calibre Web {% #calibre-web %}

Домашняя библиотека электронных книг: читать в браузере, искать, раскладывать по полкам.

**Вход:** имя `admin`, пароль `admin123`. **Смените пароль** после входа (нажмите `admin` вверху справа → «Изменить»).

**Как добавить книги:** загрузка через страницу сначала выключена. Включите её: **Admin** (вверху справа) → основные настройки → разрешить загрузку. Появится кнопка Upload.

Сайт: [github.com/janeczku/calibre-web](https://github.com/janeczku/calibre-web)

## IT Tools {% #it-tools %}

Набор мелких инструментов для технических задач: преобразование кодировок, генератор паролей, QR-коды и многое другое.

**Вход:** не нужен. Программа ничего не хранит.

Сайт: [it-tools.tech](https://it-tools.tech)

## Excalidraw {% #excalidraw %}

Доска для рисования схем от руки: планы, чертежи, схемы.

**Вход:** не нужен. Рисунки хранятся **в вашем браузере**. Чтобы не потерять рисунок, сохраните его в файл (меню → «Сохранить»).

Сайт: [excalidraw.com](https://excalidraw.com)

## Homebox {% #homebox %}

Учёт домашних вещей и запасов: что где лежит, сколько осталось, сроки годности.

**Вход:** при первом открытии нажмите **Register** и создайте учётную запись (почта и надёжный пароль). Первая учётная запись — хозяин.

Сайт: [homebox.software](https://homebox.software)

## Vaultwarden {% #vaultwarden %}

Хранилище паролей, совместимое с приложениями Bitwarden.

**При первом открытии браузер предупредит о небезопасном соединении.** Это ожидаемо: хранилищу паролей нужно защищённое соединение, и «Кладезъ» сам делает его для домашней сети. Нажмите «Дополнительно» → «Перейти на сайт».

**Вход:** нажмите **Create account** и задайте почту и главный пароль.

{% callout type="warning" title="Главный пароль нельзя восстановить" %}
Если вы его забудете, хранилище откроется уже никогда. Запишите пароль на бумаге и храните в надёжном месте.
{% /callout %}

Сайт: [github.com/dani-garcia/vaultwarden](https://github.com/dani-garcia/vaultwarden)

## Jellyfin {% #jellyfin %}

Домашний кинотеатр: фильмы, музыка, фотографии — на компьютере и на телефонах в доме.

**Первый запуск:** короткий мастер — язык, учётная запись администратора (придумайте надёжный пароль), папки с медиа.

Если компьютер слабый, некоторые видео могут подтормаживать: программе приходится перекодировать их на лету.

Сайт: [jellyfin.org](https://jellyfin.org)

## Meshtastic Web {% #meshtastic-web %}

Пульт для радиомодулей Meshtastic — связь сообщениями на километры без интернета и сотовой сети.

**Нужен сам радиомодуль.** Без него программа покажет «устройства не подключены».

**Как подключиться:** нажмите **New Connection** → **HTTP** и впишите адрес радиомодуля в вашей Wi-Fi-сети. Подключение по Bluetooth и USB здесь не работает: браузер разрешает их только на защищённых страницах.

Сайт: [meshtastic.org](https://meshtastic.org)

## Учебная платформа (Kolibri) {% #kolibri %}

Уроки с видео, упражнения и учёт успехов — для школы и самостоятельной учёбы, без интернета.

**Первый запуск:** короткий мастер — тип учреждения и учётная запись администратора (запишите пароль).

**Как добавить уроки:** **Device → Channels → Import**. Уроки скачиваются из интернета каналами; берите только нужные — их много и они большие.

Сайт: [learningequality.org/kolibri](https://learningequality.org/kolibri)

## MeshCore Web {% #meshcore-web %}

Пульт для радиомодулей MeshCore — ещё один способ связи сообщениями без интернета.

**Нужен сам радиомодуль.** Подключается к компьютеру, за которым вы сидите, по USB или Bluetooth. Лучше всего работает в Chrome или Edge.

**При первом открытии браузер предупредит о небезопасном соединении** — это ожидаемо, нажмите «Дополнительно» → «Перейти на сайт».

Сайт: [meshcore.io](https://meshcore.io)

## Библиотека в переводе {% #offline-translation %}

Переводит статьи библиотеки на другой язык прямо на компьютере, без интернета. Откройте статью — вверху появится строка **«Перевести страницу»** с кнопками языков и кнопкой **«Оригинал»**.

**Языки:** по умолчанию французский, испанский и немецкий. Чтобы изменить список: «Управление» → «Изменить» → в переменной `TRANSLATE_LANGS` впишите коды языков через запятую (например, `en,uk,de`) → «Сохранить». Для каждого нового языка нужен интернет и 45–140 МБ места.

**Перевод машинный и дословный.** Он хорошо передаёт смысл, но в медицине и вопросах безопасности сверяйтесь с оригиналом.

Не переводятся таблицы, заголовок вкладки и результаты поиска.
