# Phones over Wi-Fi

Phones and tablets at home can open the Kladez library and maps. Nothing needs to be installed on the phone — an ordinary browser is enough. No internet is needed either: the phone talks to the computer through your home Wi-Fi.

## What you need

- The computer with Kladez is switched on.
- The phone is connected to **the same Wi-Fi** as the computer (the same router).

## How to connect

1. On the computer, open Kladez. The home page shows a **QR code for phones**.
2. On the phone, open the camera and point it at the QR code. Tap the link that appears.
3. Kladez opens in the phone's browser.

Tip: add the page to the phone's home screen (browser menu → “Add to Home screen”). Next time it is one tap away.

If the QR code does not scan, type the address shown under it into the phone's browser — it looks something like `http://192.168.1.10:8080`.

## View only

From a phone you can **read** the library and **view** maps. Downloading, deleting material and changing settings is only possible on the computer itself, so nobody can accidentally erase the library from a phone.

## If the phone cannot open the page

- Make sure the phone is on the home Wi-Fi, not mobile data. Turning mobile data off for a moment sometimes helps.
- Make sure the computer is on and Kladez opens on it.
- The computer's address on the home network sometimes changes (for example after the router restarts). Open Kladez on the computer and scan the QR code again.
- Some routers do not let devices on a “guest network” see each other. Connect the phone to the main network.

## If you only have a phone

Kladez needs a computer, but similar free apps exist for phones:

- **Kiwix** — a library: download Wikipedia and other material in the app;
- **Organic Maps** — offline maps.

Download what you need in advance, while you have internet.
