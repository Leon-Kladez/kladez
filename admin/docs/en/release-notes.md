# What's new

## Version 0.1 — the first one

The first version of Kladez for Windows.

- **The whole interface is in Russian**, with a “Русский / English” switch.
- **Installer for Windows 10 and 11.** It turns on the Windows components it needs by itself; if a restart is needed, installation continues on its own afterwards. Nothing is downloaded from the internet during installation.
- **Ready-made sets** in Easy Setup: First Aid Kit, Library, Everything.
- **A Russian content catalog:** Wikipedia, medicine, textbooks, dictionaries, books. It works offline too, from a saved copy.
- **Maps of any country**, and for Russia by federal district.
- **Resumable downloads:** if the internet drops, downloading continues from the same place.
- **AI assistant** on the computer itself, answering with links to library articles.
- **Help pages** — the ones you are reading now.
