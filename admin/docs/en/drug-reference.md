# Drug reference

The drug reference is the medicine labels published by the US Food and Drug Administration (FDA). You can search them without internet: by the name of a medicine or by a complaint.

{% callout type="warning" title="Important" %}
The labels are for medicines sold **in the USA**. Names and doses where you live may differ. This is reference information, not medical advice. Always read the leaflet of the medicine in your hands and, if you can, ask a doctor or pharmacist.
{% /callout %}

The first time you open it, the drug reference shows this warning; you need to read and confirm it.

## How to download it

The drug reference is large, so it is not downloaded automatically. On the home page open the **Drug reference** tile and click **Download FDA drug data**.

- About 1.7 GB is downloaded; once prepared for search it takes **8–10 GB** of disk.
- Preparing for search takes a long time. You can close the page — it carries on by itself.
- If the internet drops, the download resumes from the same place.

## How to search

- **Search by drug** — type the name of the medicine or active ingredient, for example `ibuprofen` or `acetaminophen`.
- **By situation** — choose what is bothering you (burn, fever, diarrhea) and the reference shows suitable over-the-counter options.
- **Compare warnings** — open a medicine and put its warnings next to another medicine's. This is **not** an interaction check: ask a doctor or pharmacist whether two medicines can be taken together.

## Updates

If automatic content updates are turned on in Settings, the drug reference refreshes itself from time to time. Otherwise it stays as it was downloaded — which is fine for offline use.
