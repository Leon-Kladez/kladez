# Without internet

Kladez is made for the days when there is no internet. Everything already downloaded works without it.

## What works without internet

- **Library** — all downloaded material.
- **Maps** — the countries and regions you downloaded.
- **AI assistant** — if a model is already downloaded.
- **Drug reference** — if it is downloaded.
- **Phones at home** — over the router's Wi-Fi. The router does not need internet, only power.

## What does not work without internet

- Downloading new material, maps and models.
- Checking for updates.

Without internet Kladez does not wait or freeze: the content catalog is shown from a saved copy, and downloads resume when the connection comes back.

## Prepare in advance

While you have internet:

1. Download a content set in [Easy Setup](/easy-setup). If you have the space — “Library” or “Everything”.
2. Download the map of your region — see [Maps](/docs/maps).
3. If you use the AI assistant, download a model.
4. Check that it all opens: unplug the internet or turn off Wi-Fi for a minute and open a couple of articles.
5. Connect your family's phones — see [Phones over Wi-Fi](/docs/phones) — and show them how to open the library.

## If the power goes out too

The computer and router need electricity. A laptop lasts a few hours on battery. For a long outage, write down or print the most important things in advance: first aid, purifying water, keeping warm.
