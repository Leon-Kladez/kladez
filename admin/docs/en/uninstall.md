# Uninstalling

Kladez is removed like any other Windows program.

1. Open **Start → Settings → Apps**.
2. Find **Kladez** (written «Кладезъ») in the list and click **Uninstall**.
3. You will be asked whether to **also delete the downloaded library (articles, maps, books)**:
   - **No** — the library stays on the disk. If you install Kladez again later, nothing has to be downloaded again.
   - **Yes** — the library is deleted and the disk space is freed.
4. Wait until the uninstall finishes.

The desktop shortcut, autostart and the log folder are removed with the program. The Windows components that the installer turned on (Windows Subsystem for Linux) stay — they do no harm and other programs may use them.

## If you only need disk space

You do not have to uninstall. Remove material you do not need one item at a time: Settings → **[Content Manager](/settings/zim)**, and maps in Settings → **[Maps Manager](/settings/maps)**.
