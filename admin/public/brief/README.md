# Ролик «Бриф»

Сюда кладутся файлы приветственного ролика «Бриф» (≈3 минуты, «зачем нужен Кладезъ»).
Они попадают в образ панели вместе с остальной папкой `public/` и показываются без интернета.

| Файл | Для чего | Кадр |
|---|---|---|
| `kladez-brief-16x9.mp4` | компьютер, планшет «лёжа» | 1280×720 |
| `kladez-brief-9x16.mp4` | телефон, экран «стоя» | 720×1280 |

Требования к каждому файлу:

- контейнер MP4, видео H.264 (профиль High или Main, `yuv420p`), звук AAC-LC 44,1 или 48 кГц, стерео;
- `-movflags +faststart` (индекс в начале файла — ролик начинает играть сразу, работает перемотка);
- размер — не больше 50 МБ;
- без внешних ссылок и встроенных субтитров на чужих серверах.

Пример сборки из готового исходника:

```bash
ffmpeg -i brief-16x9-master.mov -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 23 -preset slow -vf scale=1280:720 -c:a aac -b:a 128k -movflags +faststart kladez-brief-16x9.mp4
ffmpeg -i brief-9x16-master.mov -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 23 -preset slow -vf scale=720:1280 -c:a aac -b:a 128k -movflags +faststart kladez-brief-9x16.mp4
```

Как это работает:

- Пока файлов нет, кнопки «Бриф» и окна с роликом нет — никаких ошибок.
- Можно положить только один файл — тогда он показывается на всех экранах.
- Панель проверяет папку раз в минуту: перезапускать её после того, как положили файл, не нужно.
- При первом входе на главную ролик открывается сам; после закрытия браузер запоминает это (localStorage)
  и дальше ролик открывается только кнопкой «Бриф» справа вверху. На сервер ничего не отправляется.
