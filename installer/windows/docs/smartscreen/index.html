Как пройти предупреждение Windows

Когда вы запускаете установщик «Кладезъ», Windows или браузер могут предупредить: «файл может навредить». Так бывает со всеми программами, у которых нет платной электронной «подписи». «Кладезъ» — бесплатный проект, подписи у него пока нет.

Предупреждение не значит, что в файле вирус: Windows просто не знает этого издателя. Чтобы убедиться, что файл настоящий, сверьте его контрольную сумму (раздел в конце страницы).

1. Синее окно «Windows защитила ваш компьютер»

  1. Нажмите на слова «Подробнее» (они написаны мелко, под текстом).
  2. Внизу появится кнопка «Выполнить в любом случае» — нажмите её.
  3. Windows спросит разрешение на изменения — нажмите «Да».

2. Предупреждение браузера при скачивании

Иногда браузер не сразу сохраняет файл, потому что его «редко скачивают».

  • Microsoft Edge: в списке загрузок наведите на файл, нажмите «…» → «Сохранить». Если спросит ещё раз — «Показать больше» → «Всё равно сохранить».
  • Google Chrome: в списке загрузок нажмите на стрелку или «…» рядом с файлом → «Сохранить» (или «Всё равно скачать»).
  • Яндекс Браузер: в загрузках нажмите «Продолжить скачивание» или «Всё равно скачать». Если браузер пишет, что файл «может быть опасен», — сверьте контрольную сумму после скачивания.

3. Защитник Windows

Изредка Защитник Windows может по ошибке отправить установщик «на карантин». Если файл пропал сразу после скачивания:

  1. Откройте «Пуск» → «Параметры» → «Обновление и безопасность» (в Windows 11 — «Конфиденциальность и защита») → «Безопасность Windows» → «Защита от вирусов и угроз» → «Журнал защиты».
  2. Найдите строку с «Кладезъ-установка», нажмите «Действия» → «Восстановить».

Делайте это, только если контрольная сумма файла совпала (см. ниже).

Как проверить, что файл настоящий

У каждого файла есть «отпечаток» — контрольная сумма SHA-256. Если в файле изменили хоть один байт, отпечаток будет другим. Настоящий отпечаток опубликован рядом со ссылкой на скачивание (файл SHA256SUMS.txt).

  1. Откройте папку «Загрузки», где лежит установщик.
  2. Нажмите на адресную строку папки, сотрите текст, напишите cmd и нажмите Enter — откроется чёрное окно.
  3. Напишите в нём (имя файла можно не печатать целиком: начните и нажмите Tab): 
    certutil -hashfile Кладезъ-установка-0.1.0.exe SHA256
  4. Сравните длинную строку из букв и цифр с той, что опубликована. Совпадает — файл настоящий.
